## GOODS RECEIPT DATE — A COMMON WRONG GUESS
- `PostingDate` and `DocumentDate` are on `A_MaterialDocumentHeader` (keyed by MaterialDocumentYear +
  MaterialDocument), NOT on `A_MaterialDocumentItem` (keyed by PurchaseOrder + PurchaseOrderItem, which is
  what you query to find the goods receipt for a PO line). Selecting either on the item entity 404s — this
  is not a hypothetical, it is the single most common wrong guess on this skill. If you need the receipt's
  date, read the item first for the key fields (MaterialDocumentYear, MaterialDocument), then read the
  header by that key for PostingDate/DocumentDate — two reads, not one, because they are two entities.

## THIS SERVICE'S FUNCTION IMPORTS
- The A_SupplierInvoice entity is NOT updatable — do NOT attempt to update PaymentBlockingReason or status
  directly. Use a function import instead.
- Call `odata_function_import` with the function name and the params pinned under SAP SERVICE's Function
  Imports for this service, each value pre-formatted as its OData V2 URI literal per SAP FUNCTION IMPORTS
  (Edm.String quoted, Edm.Boolean lowercased):
  - **Release blocked invoice**: function `Release` — SupplierInvoice, FiscalYear, DiscountDaysHaveToBeShifted
  - **Post parked invoice**: function `Post` — SupplierInvoice, FiscalYear, and optionally DocumentDate/PostingDate
  - **Cancel invoice**: function `Cancel` — SupplierInvoice, FiscalYear, PostingDate, ReversalReason
- There is **no Park function import** on this service. Cases reach you because an invoice already exists in
  SAP, so the operation you need is Release (clear a block) or Post (an invoice parked upstream) — never Park.
